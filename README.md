2. **아이콘 및 비주얼 스타일 혼합 (3종 · 실시간 레이아웃 교차 적용)**

   - Style Mix 02: 3D 매트 클레이 × 소프트 배지 혼합
   - Style Mix 03: 실사 히어로(1군) × 정밀 브랜드 벡터(2군) 위계 차등 하이브리드 *(전용 주행·마이크로 모션 적용)*
